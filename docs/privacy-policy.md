# Privacy Policy — BookRadar

**Last updated: November 14, 2026**

## 1. Introduction

BookRadar is a Chrome browser extension designed to help users save and organize book pre-orders, track release dates, and receive reminders.

This Privacy Policy explains how BookRadar accesses, uses, and stores information.

## 2. Information We Access

BookRadar accesses the following information to provide its features:

- **Active tab information:** The title and URL of the active browser tab, used to prefill book details.
- **Page metadata:** The Open Graph image URL (`og:image`) from the active page, used to display book covers.
- **Book information:** Book titles, authors, pre-order dates, release dates, store URLs, statuses, and associated cover image URLs.
- **Reminder preferences:** Notification settings and selected reminder times.

BookRadar does not require account registration or request personal information such as names, email addresses, or passwords.

## 3. How Information Is Used

Information is used exclusively to provide BookRadar's functionality, including:

- Saving and managing book information.
- Displaying book covers.
- Tracking pre-order and release dates.
- Scheduling and displaying browser notifications.
- Searching, filtering, and updating saved books.

BookRadar does not use this information for advertising, profiling, or analytics.

## 4. Data Storage

Saved books and reminder preferences are stored locally in the user's browser using the Chrome Storage API (`chrome.storage.local`).

BookRadar does not operate a remote database or backend server for storing user information.

Saved information is not automatically synchronized between devices by BookRadar.

## 5. Third-Party Services

BookRadar does not intentionally transmit saved book collections or reminder preferences to external services.

Book cover images may be loaded from third-party websites using image URLs obtained from page metadata. When these images are displayed, the browser may make requests to the websites hosting them. Such requests are subject to the respective websites' privacy practices.

BookRadar does not control these third-party websites.

## 6. Browser Permissions

BookRadar uses the following Chrome permissions:

- **storage:** To store book information and reminder preferences locally.
- **activeTab:** To access the active tab's title and URL.
- **scripting:** To retrieve the book cover image URL from the active page's metadata.
- **alarms:** To schedule reminders for book release dates.
- **notifications:** To display book-related reminders.

These permissions are used solely to support the extension's features.

## 7. Data Sharing

BookRadar does not sell, rent, or share stored book information with advertisers or data brokers.

BookRadar does not use third-party analytics or advertising services.

## 8. Data Retention and Deletion

Saved book information remains in local browser storage until the user deletes it or Chrome removes the extension's stored data.

Users can delete individual books directly within BookRadar.

Removing the extension normally removes its locally stored extension data.

## 9. Children's Privacy

BookRadar is a general-purpose book organization tool. It does not knowingly collect personal information from children.

## 10. Changes to This Privacy Policy

This Privacy Policy may be updated if BookRadar's functionality or data practices change.

The latest version will be made available through the extension's published Privacy Policy page.
